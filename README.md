# FM27 中国女超真实数据库

当前版本基于 FM26 所需字段制作，待 FM27 正式发布后再调整字段和编辑器格式。

## 当前内容

- 12 支中国女超球队公开阵容数据
- 球员英文/拼音名、位置、CA、PA
- 按位置排名前 50 名清单
- 位置排名已按最近中国女子金球奖结果进行人工校准
- 王霜 CA 160；门将排名按肖梓彤、刘晨、陈晨、潘红艳、朱钰调整
